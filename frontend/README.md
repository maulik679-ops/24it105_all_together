# Student Portfolio - React + Vite

## Overview

A simple **Student Portfolio** application built using **React** and **Vite**. It demonstrates reusable components, React Router, state management with `useState`, and GitHub API integration.

## Features

- Reusable React components
- React Router v6 navigation
- Home, Projects, Contact, and 404 pages
- Dark/Light theme toggle
- Contact form with controlled input
- GitHub API integration
- Loading spinner and error handling
- Repository search and retry button
- Repository star count

## Technologies Used

- React
- React Router DOM
- Vite
- JavaScript (ES6)
- JSX
- CSS
- GitHub REST API
